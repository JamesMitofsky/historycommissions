# Hello World

Welcome to this minimalist blog. This post is rendered directly from a Markdown file.

## What is this?

A clean, fast blog engine built with Next.js 16, TypeScript, and Tailwind CSS. Posts live as plain `.md` files in the `content/posts/` directory.

## Writing a Post

Drop any `.md` file into `content/posts/` and it will automatically appear on the blog. The filename becomes the URL slug — `hello-world.md` becomes `/posts/hello-world`.

## Markdown Features

**Bold text**, _italic text_, and `inline code` all work out of the box.

### Code Blocks
